📊 La Chuleta Definitiva: Express Tradicional vs Strapi v5

EQUIVALENCIAS
Muchos desarrolladores se confunden al pasar de Node/Express puro a Strapi porque buscan res.json() o req.body. Esta tabla muestra la traducción exacta entre ambos mundos.
Operación En Express Tradicional En Strapi v5 (Koa Context) Explicación Clave
Leer datos del cliente req.body ctx.request.body?.data ?? ctx.request.body Strapi suele envolver payloads en { "data": { ... } }.
Responder con JSON res.status(200).json(datos) ctx.body = { data: datos } En Strapi solo asignas a ctx.body. No uses res.json().
Código de estado HTTP res.status(201) ctx.status = 201; Se asigna directamente como propiedad numérica al contexto.
Parámetros de URL (/items/:id) req.params.id ctx.params.id Idéntica sintaxis accesible desde el objeto ctx.
Parámetros de consulta (?estado=...) req.query.estado ctx.query.estado Koa parsea automáticamente la URL en ctx.query.
Escribir Cookie Segura res.cookie("token", val, { httpOnly: true }) ctx.cookies.set("token", val, { httpOnly: true }) En Strapi se usa el método ctx.cookies.set(...) de Koa.
Invocar Lógica de Negocio await MiServicio.hacerAlgo() strapi.service('api::orden.custom-orden').metodo() Strapi desacopla servicios usando localizador de dependencias global.
Acceso a Base de Datos await MiModelo.create(data) strapi.db.query('api::orden.orden').create({ data }) Strapi ORM administra las consultas sobre PostgreSQL de forma tipada.
Manejo de Errores next(error) ctx.throw(400, "Mensaje") o ctx.status = 400; ctx.body = { error } Evita tirar el proceso; Strapi formatea la respuesta en JSON.
ESTRUCTURA OFICIAL STRAPI

¿Cómo se organiza una API en Strapi (`src/api//`)?

STRAPI BLUEPRINT
La Anatomía de Strapi: En Strapi, cada entidad del negocio es un módulo autónomo dentro de src/api/<nombre-api>/. Esta arquitectura desacoplada permite que el equipo de desarrollo cree modelos, rutas y controladores sin mezclar código ni generar dependencias circulares.

1. content-types/<api>/schema.json

El Esquema del Modelo: Define el nombre de la tabla en PostgreSQL (collectionName), los atributos (string, decimal, enumeration, json), longitudes mínimas y relaciones. Strapi genera las migraciones de base de datos a partir de este JSON.

2. routes/<api>.js (Core Router)

El Enrutador Core: Usa factories.createCoreRouter('api::orden.orden') para autogenerar de inmediato el CRUD estándar (find, findOne, create, update, delete).

3. routes/custom-<api>.js (Custom Router)

Las Rutas Custom OMS: Exporta un objeto { routes: [...] } con endpoints adicionales que no pertenecen al CRUD básico, como /preview para simulaciones o /schema para metadatos.

4. controllers/<api>.js (Core Controller)

El Controlador Core: Usa factories.createCoreController para conectar el router base con el Entity Service nativo de Strapi.

5. controllers/custom-<api>.js

El Controlador Personalizado (ctx): Recibe el contexto Koa (ctx), extrae el cuerpo con ctx.request.body?.data ?? ctx.request.body, delega en strapi.service y responde asignando a ctx.body y ctx.status.

6. dtos/<api>.dto.js

El Filtro de Seguridad (Whitelist): En APIs públicas o federadas, limpia espacios en blanco, descarta atributos prohibidos (ej. esAdmin: true) y congela el objeto con Object.freeze().

7. services/<api>.js (Core Service)

El Servicio Core: Usa factories.createCoreService para exponer operaciones nativas sobre el motor de base de datos de Strapi.

8. services/custom-<api>.js

El Cerebro de Negocio: Ejecuta cálculos matemáticos (IVA del 12%), valida transiciones de estado, interactúa con strapi.db.query y ejecuta el dry-run del /preview.

01 / CONTENT-TYPE STRAPI · 5 MIN

El Esquema de Datos (`schema.json`)

Punto de Partida en Strapi: Todo en Strapi nace de un schema.json. En este archivo declaras qué campos existen, qué tipos de datos aceptan (string, decimal, enumeration, json) y cuáles son obligatorios. Strapi se encarga de crear las tablas en PostgreSQL automáticamente.

02 / RUTAS EN STRAPI · 5 MIN

El Enrutador Core y el Enrutador Custom OMS

Rutas Custom vs Core en Strapi: Las rutas core con factories.createCoreRouter cubren el CRUD básico. Pero en OMS requerimos endpoints como POST /ordenes/preview y GET /ordenes/schema. Strapi te permite crear un archivo adicional (ej: routes/custom-orden.js) con un arreglo de rutas que se fusionan sin sobreescribir el core.

03 / CONTROLADOR STRAPI · 5 MIN

El Manejo del Contexto Koa (`ctx`) en Strapi

¿Por qué en Strapi usamos `ctx` y no `req/res`?: Strapi funciona sobre Koa.js en su capa HTTP. Koa fusiona `request` y `response` en un único objeto llamado `ctx` (Context). En Strapi, para enviar datos basta con asignar ctx.body = resultado y ctx.status = 201; no necesitas llamar a res.json() ni a res.send().
api/src/api/orden/controllers/custom-orden.js 


1const getCustomService = (strapi) => strapi.service("api::orden.custom-orden");


2const getPayload = (ctx) => ctx.request.body?.data ?? ctx.request.body ?? {};


3


4export default ({ strapi }) => ({


5  async preview(ctx) {


6    ctx.body = await getCustomService(strapi).preview(getPayload(ctx));


7  },


8  async create(ctx) {


9    const dto = new CrearOrdenDTO(getPayload(ctx));


10    const nuevaOrden = await getCustomService(strapi).create(dto);


11    ctx.status = 201;


12    ctx.body = { data: nuevaOrden };


13  }


14});

04 / DTOs & SANITIZACIÓN · 4 MIN

El Escudo de Datos (Whitelist & Inmutabilidad)

Protección contra Mass Assignment: En Strapi, el DTO actúa antes del servicio para filtrar con una lista blanca y congelar la instancia con Object.freeze(), descartando campos maliciosos como esAdmin: true.
api/src/api/orden/dtos/orden.dto.js 


1export class CrearOrdenDTO {


2  constructor(payload = {}) {


3    this.cliente = String(payload.cliente || "").trim();


4    this.servicio = String(payload.servicio || "").trim().toLowerCase();


5    this.monto = Number(payload.monto);


6    this.estado = "borrador";


7    Object.freeze(this);


8  }


9}

05 / SERVICIOS STRAPI · 5 MIN

Lógica de Negocio y Consumo con `strapi.service`

La Regla de Oro en Strapi: Los controladores son delgados ("thin controllers"). Toda la matemática financiera (cálculo del IVA 12%), reglas de negocio e interacción con strapi.db.query vive en services/custom-orden.js.
api/src/api/orden/services/custom-orden.js 


1const TASA_IVA = 0.12;


2export default ({ strapi }) => ({


3  async create(payload) {


4    const subtotal = Number(payload.monto);


5    const impuesto = Number((subtotal * TASA_IVA).toFixed(2));


6    const total = Number((subtotal + impuesto).toFixed(2));


7    return await OrdenModel.create({ ...payload, impuesto, total });


8  },


9  preview(payload) {


10    const subtotal = Number(payload.monto || 0);


11    return { simulacion: true, total: subtotal * 1.12 };


12  }


13});

06 / CUSTOM ENDPOINTS OMS · 4 MIN

El Patrón `/preview` y `/schema` de OMS

Por qué estos endpoints diferencian a OMS: En un sistema operativo como OMS, los usuarios necesitan previsualizar el cálculo de tarifas e impuestos antes de confirmar un trámite. El endpoint POST /ordenes/preview valida el payload y calcula el total sin generar registros en base de datos. Asimismo, GET /ordenes/schema entrega la definición dinámica de atributos para que el frontend no tenga formularios quemados en código estático.

GUÍA DE RESOLUCIÓN DE PROBLEMAS

🩺 Centro de Diagnóstico: Errores Frecuentes en Strapi

SOLUCIONES
Cuando los estudiantes desarrollan en Strapi, se topan con errores recurrentes de configuración. Aquí tienen la causa raíz y la solución exacta con código.
404 NOT FOUND
"Mi ruta custom da 404 a pesar de haber creado el archivo"
Causa: Falta config: { auth: false } en la ruta o el archivo no está en src/api/<api>/routes/.
Solución: En Strapi por defecto los endpoints son privados. Agrega config: { auth: false } en el objeto de la ruta o habilita el permiso en el panel de Strapi en Settings > Users & Permissions > Roles > Public.
TYPEERROR
"Cannot read properties of undefined (reading 'data')"
Causa: Intentar hacer const { cliente } = ctx.request.body.data; cuando el cliente envió JSON plano sin envolver.
Solución: Usa siempre el helper estándar de OMS: const getPayload = (ctx) => ctx.request.body?.data ?? ctx.request.body ?? {};.
CRASH
"res.json is not a function o res.status is not a function"
Causa: Intentar usar la sintaxis de Express en un controlador de Strapi.
Solución: Strapi corre sobre Koa.js. No uses res.json(). Para responder en Strapi debes asignar: ctx.body = misDatos; y ctx.status = 200;.
ORPHAN SERVICE
"strapi.service(...) is undefined"
Causa: Error en el identificador UID del servicio. El formato obligatorio es api::<nombre-api>.<nombre-archivo-servicio>.
Solución: Si tu archivo es services/custom-orden.js dentro de src/api/orden/, debes invocar: strapi.service('api::orden.custom-orden').
BD OUT OF SYNC
"Agregué un campo al schema.json pero no se guarda en PostgreSQL"
Causa: Strapi no está corriendo en modo desarrollo o hay un error de sintaxis en el JSON.
Solución: Inicia Strapi con npm run develop (o strapi develop). En este modo, Strapi analiza las diferencias en schema.json y ejecuta automáticamente el ALTER TABLE en PostgreSQL.
SECURITY
"¿Cómo evito que un usuario se auto-apruebe una orden?"
Causa: Guardar directamente ctx.request.body sin filtrar.
Solución: Pásalo siempre por un DTO (new CrearOrdenDTO(...)) que fuerce this.estado = 'borrador' y congele la instancia con Object.freeze(this).

📖 Glosario de Términos Strapi v5 & Node.js para Alumnos

GLOSARIO
Koa Context (ctx)
Objeto central de Koa y Strapi que encapsula la petición y la respuesta HTTP. En Strapi, para enviar datos basta con asignar ctx.body = ... y ctx.status = 201.
ctx.request.body.data
Convención estándar de Strapi donde los payloads enviados por el cliente vienen envueltos dentro de una propiedad data. En los controladores se usa ctx.request.body?.data ?? ctx.request.body para dar soporte universal.
Strapi Core Factories
Funciones nativas de Strapi (factories.createCoreRouter, factories.createCoreController, factories.createCoreService) que generan el código base CRUD automáticamente para no reinventar la rueda.
strapi.service()
Localizador de servicios de Strapi. Permite que cualquier controlador o tarea invoque la lógica de negocio de otra entidad mediante su identificador UID (ej: strapi.service('api::orden.custom-orden')).
schema.json (Content-Type)
Archivo declarativo donde se definen los atributos, tipos de datos, restricciones y relaciones de una entidad. Strapi lo lee para sincronizar las tablas de base de datos en PostgreSQL.
DTO (Data Transfer Object)
Objeto que transporta datos entre procesos o capas. En seguridad web, actúa como lista blanca (whitelist) para filtrar atributos peligrosos o no autorizados enviados por atacantes en el cuerpo de la petición.
Dry-Run / Preview
Técnica arquitectónica implementada en OMS donde se simula el cálculo financiero de una orden y se validan reglas de negocio en memoria sin persistir ningún dato en PostgreSQL.
Object.freeze()
Método de JavaScript que 'congela' un objeto, impidiendo que se agreguen nuevas propiedades, se eliminen existentes o se cambien sus valores. Esencial para garantizar inmutabilidad en DTOs.
